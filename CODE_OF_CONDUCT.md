# Community code of conduct

Keep this project welcoming and useful. Treat contributors and users with respect,
consider accessibility and language differences, and discuss ideas without
personal attacks. Harassment, discriminatory behavior, threats, sexualized content,
spam and disclosure of another person's private information are not acceptable.

Use invented financial examples. Never pressure someone to reveal income,
accounts, identity details or a real plan link to obtain support.

The maintainer may edit/remove harmful content, close a discussion, or restrict
participation to protect the community. Enforcement should be proportionate and
based on behavior rather than identity.

To report a concern privately, use a private contact method published on the
[maintainer's profile](https://github.com/tombelieber). If none is available, ask
for a private contact channel without publishing personal details or allegations.
Security vulnerabilities should follow [SECURITY.md](SECURITY.md).

These standards apply to project issues, pull requests and other spaces operated
by the project.
